# The Diamond Capsule of Life

Лендинг проекта «Алмазная капсула жизни» и полная статья одним сайтом.
Чистая статика: HTML + CSS + немного JS, без сборки и зависимостей.

## Что внутри

```
diamond-capsule-of-life/
├── index.html               лендинг (EN): миссия, капсула, запись, запуск, послание, форма
├── article.html             статья (RU): 12 разделов, оглавление, прогресс чтения
├── assets/
│   ├── css/base.css         общие токены, шапка, кнопки, футер
│   ├── css/landing.css      тёмный «космос»: hero, схема капсулы, спеки, блоки
│   ├── css/article.css      светлая «бумажная» тема для лонгрида
│   ├── js/landing.js        звёздное поле на canvas, параллакс, появление секций, форма
│   └── js/article.js        индикатор прогресса чтения + подсветка оглавления
├── .nojekyll                чтобы GitHub Pages не трогал файлы Jekyll-ем
└── README.md
```

## Локальный просмотр

Просто открыть `index.html` двойным щелчком. Если нужен http-сервер:

```powershell
python -m http.server 5500
# затем http://127.0.0.1:5500
```

## Публикация на GitHub Pages

Репозиторий должен называться так, как хотите видеть адрес. Для `https://<ник>.github.io` —
имя `<ник>.github.io`; для подпроекта — любое, тогда адрес будет `https://<ник>.github.io/<репо>/`.

```powershell
cd diamond-capsule-of-life
git init
git add .
git commit -m "The Diamond Capsule of Life: landing + article"
git branch -M main
git remote add origin https://github.com/<ник>/<репо>.git
git push -u origin main
```

Дальше: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
Branch: `main`, folder `/ (root)` → Save**. Через минуту сайт будет доступен.

Сайт в подкаталоге работает без правок: все пути относительные.

## Что реализовано

**Лендинг (EN)**
- Hero на весь экран: canvas-звёздное поле с параллаксом, SVG-капсула (алмаз в шестигранной
  оболочке с орбитами и спутником), появление элементов при скролле.
- Секции: Mission, Diamond Capsule (схема с выносками 01–05), Recording, Launch,
  The Message (послание), Take part (форма).
- Цифры из статьи: 3,5 млрд лет, период полураспада ДНК 521 год, 14,8 Тбит/см³,
  1,85 ТБ/см³, ~1 200 геномов в см³, 16,6 км/с, $7 000/кг, 20 % c.

**Статья (RU)**
- 12 разделов, автоматические номера, буквица, выноски, блок послания, список источников
  с рабочими ссылками на DOI/arXiv.
- Липкое оглавление со scroll-spy и полоса прогресса чтения.

**Доступность и мелочи**
- `prefers-reduced-motion` отключает анимации и звёздное поле.
- Семантика, `aria`-атрибуты, focus-visible, печатные стили для статьи.
- Мобильная вёрстка: бургер-меню, одноколоночные сетки, скрытие оглавления.

## Ограничения

- Форма — демонстрационная: данные никуда не отправляются, бэкенда нет.
- Шрифты (Space Grotesk, Newsreader, Inter) грузятся с Google Fonts; без интернета
  сработает системный стек.
- Изображений нет: вся графика — SVG и CSS, поэтому страница весит десятки килобайт.

## Источник текста

Статья Владимира Яковлева «Алмазная капсула жизни: как записать человечество на алмаз
и рассеять его по Галактике, как споры» (2026). Файл `Геном (2).txt` → `article.html`
собирается скриптом `build_article.py` (лежит в родительской папке рабочей области).
