# Life Kapsule

Демо-проект капсульного мини-отеля: лендинг и личный кабинет. Чистая статика —
без сборки, зависимостей и интернета (шрифт Manrope подгружается с Google Fonts,
но при его отсутствии срабатывает системный стек).

## Структура

```
life-kapsule/
├── index.html          # лендинг: hero, капсулы, как работает, отзывы, форма брони, FAQ
├── lk.html             # личный кабинет: брони, бонусы, профиль
└── assets/
    ├── css/style.css   # все стили, тёмная тема, адаптив
    └── js/app.js       # бронирование, localStorage, меню, статусы броней
```

## Как открыть

Двойной клик по `index.html` — работает из файловой системы.
Если нужен локальный сервер (например, для корректных путей при отладке):

```powershell
# любой из вариантов
python -m http.server 5500
npx serve .
```

## Что реализовано

- **Лендинг**: hero с CSS-иллюстрацией капсулы, 4 преимущества, 3 тарифа,
  4 шага заселения, отзывы, FAQ на `<details>`, адаптивное меню-бургер.
- **Бронирование**: выбор капсулы карточкой → автоподстановка в форму,
  расчёт ночей и суммы на лету, валидация дат/имени/телефона,
  сохранение брони в `localStorage` (ключ `lk_bookings`), переход в кабинет.
- **Личный кабинет**: список броней со статусами (подтверждена / скоро / идёт /
  завершена), отмена, сводка (брони, ночи, потрачено), бонусы 5 %,
  профиль из последней брони.
- **Доступность**: focus-visible, aria-атрибуты, `prefers-reduced-motion`,
  семантические теги, `role="alert"` у ошибки формы.

## Ограничения демо

- Нет бэкенда: данные живут только в браузере, оплата не списывается.
- Нет авторизации: кабинет открывается сразу (это осознанно — демо для показа).
- Даты в календаре ограничены «сегодня» и позже.
